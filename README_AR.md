# صانع الشهادات الاحترافي — Professional Certificate Maker

مشروع Flutter (أندرويد، عربي RTL، يعمل دون إنترنت). مبني بنفس أسلوب مشروع «صندوق قعشان»: ارفع كل محتويات المجلد إلى جذر المستودع ثم شغّل **Actions ← Build Android APK** (يولّد ملفات أندرويد الناقصة بـ `flutter create` ويبني `app-release.apk`).

## ما الذي يعمل (مكتوب، غير مُختبَر بعد على جهاز)
- **المحرر**: نص / صورة / أشكال (مستطيل، مربع، دائرة، خط، مثلث، مضلع، نجمة) / إطارات وزخارف إسلامية / QR / توقيع باللمس؛ سحب، تغيير حجم، تدوير، تكرار، حذف، قفل، ترتيب الطبقات، محاذاة وتوزيع، تحديد متعدد، تجميع، نسخ/لصق، تراجع/إعادة (السحب = خطوة واحدة)، خطوط محاذاة ذكية، لوحة طبقات، تكبير.
- **القوالب**: 30 قالبًا في 12 تصنيفًا (`assets/templates/templates.json`، عناصر مستقلة قابلة للتحرير، `schema` مُتحقَّق منه). يُعاد توليدها بـ `python3 tools/gen_templates.py`. قوالب خاصة: المحرر ← ⋮ ← حفظ كقالب.
- **محرك رسم واحد** (`lib/painter.dart`) للمعاينة والتصدير. **التصدير**: PDF / PNG / JPG بدقة 150/300/600، هامش، مقاس ورق، خلفية شفافة (PNG).
- **الإصدار الجماعي**: CSV / XLSX / إدخال يدوي، ربط الأعمدة، معاينة، كشف الفارغ والمكرر، ترقيم، تتابعي مع حفظ التقدم، إيقاف واستكمال، PDF مدمج + PNG + ZIP.
- **المؤسسات** (شعار/توقيع/ختم تُدرج تلقائيًا عبر `@org_logo` …)، **المشاريع** (حفظ تلقائي، نسخ، سلة محذوفات)، **أرشيف الشهادات** (نسخة ثابتة من التصميم)، **مكتبة الأصول**، **نسخ احتياطي/استعادة** (ZIP + manifest + crc32).

## قرارات تقنية يجب أن تعرفها (انحرافات عن المواصفة)
| المواصفة | ما نُفِّذ | السبب |
|---|---|---|
| Drift + SQLite | ملف JSON ذرّي + نسخة سابقة (كمشروع قعشان) | Drift يحتاج `build_runner`، ولا يمكن التحقق منه هنا؛ البنية مفصولة في `store.dart` ويمكن ترحيلها لاحقًا |
| Riverpod + GoRouter | `ChangeNotifier` + `Navigator` | تقليل الاعتماديات وخطر فشل البناء |
| خطوط Cairo/Amiri… | استُبدلت بخطوطك العشرين المدمجة | `assets/fonts` (يُعاد توليدها بـ `tools/build_fonts.py`). 9 خطوط نص عربي، 1 إنجليزي، 10 رموز/زخارف مع «جدول الرموز» في المحرر. ملفات TTF إضافية تُحمَّل تلقائيًا أيضًا |
| نص قابل للتحديد في PDF | صفحات PDF صور JPEG عالية الدقة | يضمن ظهور العربية متصلة كما في المعاينة |
| PDF واحد لمئات الشهادات | يُقسَّم كل 50–100 صفحة | حماية الذاكرة؛ ZIP يجمعها |
| QR تحقق | QR يحمل نصًا (مثل رقم الشهادة) فقط | لا توجد خدمة تحقق |

## لم يُنفَّذ / لم يُختبر
- لم أستطع تشغيل `flutter analyze` أو `flutter test` أو بناء APK (لا يوجد Flutter SDK في بيئتي). قد تظهر أخطاء تجميع بسيطة عند أول بناء؛ أرسل لي سجل الخطأ وأصلحه.
- اختبارات الوحدة في `test/core_test.dart` (القوالب، التراجع، المحاذاة، CSV…) مكتوبة وغير مُشغَّلة. لا توجد اختبارات تصدير/عربية/500 شهادة على جهاز فعلي.
- إزالة خلفية التوقيع: إزالة البياض فقط. ترحيل قاعدة البيانات: توجد `schema` فقط دون ترحيلات فعلية بعد.

## التشغيل محليًا
```
flutter create --platforms=android --project-name certificate_maker .
flutter pub get && flutter test && flutter build apk --release
```
العينة: `assets/sample_data/sample_names.csv`.

## الخطوط
- **نص عربي** (تغطية كاملة + تشكيل + أشكال الحروف): الفارس، ثلث ديكوتايب، حاسن لاينر (خفيف/عريض)، حاسن بروموتر، حاسن فانيلا، محمد (عريض/عناوين/لاحا). القوالب تستخدم الثلث للأنماط الكلاسيكية والإسلامية وحاسن للعصرية.
- **Edwardian Script**: إنجليزي فقط. **رموز/زخارف** (أرابيسك، عيد، رمضان، فنان، الحر، سلطان، أيقونات): ليست لكتابة الجمل؛ اختر الخط ثم «جدول الرموز». خطوط AraSym Eid 1/2 وRamadan 1 بترميز Symbol قديم، **تحقق من ظهورها على جهاز فعلي**.
- تباعد الحروف لا يُطبَّق على النص العربي حفاظًا على اتصال الحروف.

## التفعيل (PDF والطباعة)
- تصدير PDF والطباعة (والإصدار الجماعي بصيغة PDF) مقفلة حتى يفعّلها المبرمج **أحمد داود طه شريف — 771274134**. PNG وJPG غير مقفلين.
- **مولّد الأكواد بصفحة HTML**: افتح `tools/activation_generator.html` في متصفح الجوال (يعمل دون إنترنت)، الصق المفتاح الخاص ومعرّف الجهاز، فيظهر الكود مع زر نسخ ومشاركة. الصفحة لا تحتوي المفتاح الخاص، وتتحقق أنه يطابق مفتاح التطبيق. (أداة بايثون `make_activation.py` تعطي الكود نفسه.)
- التدفق: المستخدم يفتح شاشة التفعيل ← يرسل «معرّف الجهاز» ← المبرمج يشغّل `python3 tools/make_activation.py PCM-XXXX-XXXX-XXXX activation_private_key.pem` ← يرسل الكود ← يلصقه المستخدم.
- التوقيع Ed25519: المفتاح العام داخل التطبيق والخاص `activation_private_key.pem` لدى المبرمج فقط (**لا يُرفع للمستودع، وإن ضاع لا يمكن إصدار أكواد**). الكود مربوط بجهاز واحد ولا يُنسخ بالنسخ الاحتياطي.
- حدود صريحة: يعمل دون إنترنت، لكن من يعدّل ملف APK نفسه قد يتجاوز القفل (لا حماية مطلقة في تطبيق أندرويد)، كما يمكنه مشاركة PNG وطباعته من تطبيق آخر.
